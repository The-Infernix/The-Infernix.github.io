PROJECT / 001 · FEATURED PUBLIC REPO · SIH 26171

Privacy-preserving browser agent

PRIVYSE

Your screen never leaves the device — and you can watch the gate.

Most computer-use agents ship raw screenshots — every email, ID, and password — to a remote vision model. PRIVYSE changes the order of operations: the page is understood and sanitized on-device, a fail-closed gate proves the payload is clean, and only then does the model reason.

01 Capture 02 Sanitize 03 Gate 04 Reason 05 Act
PII F1 0.984 30/30 adversarial blocked 27/27 guard tests 0 MB raw data off-device

What I built: the tiered sanitizer and zero-leak gate, on-device MobileViT/BlazeFace/OCR perception, and the FastAPI + Ollama reasoning server with perception-driven model routing.

TypeScript · WXT · MV3FastAPIOllama · Qwen2.5-VLMobileViT · ONNX

PROJECT / 002 PUBLIC REPO · HH GOA

Multilingual voice RAG

VOICE-RAG

Ask out loud. Get grounded answers — or an honest refusal.

A voice-first retrieval system across English, Hindi, Gujarati, and Telugu. Calibrated relevance floors refuse off-corpus questions instead of hallucinating; a grounding guard blocks any answer not traceable to retrieved text.

Speech Transcribe Retrieve Guard Cited answer
P50 56 ms 178 tests 4 languages

What I built: FastAPI pipeline with E5 embeddings over the 40K-passage MSMARCO-XI corpus, Sarvam speech-to-text, per-language refusal floors, and a zero-build vanilla-JS interface.

Python · FastAPIRAGSarvam STT

SourceTrail

Don't just check the claim. Trace the story.

Built for the UNESCO "Play Your Part" hackathon. A deterministic investigation engine that never issues a True/False verdict — it reconstructs where media came from, what changed, and what evidence exists.
